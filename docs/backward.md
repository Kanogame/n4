Проблема в **первом (неверном) варианте** в том, что он пытается выполнить `backward_pass()` ДО того, как обработаны все зависимости узла. 

## Пример: выражение `(a + b) * c`

Пусть у нас есть вычислительный граф:
```
    a   b
     \ /
      +   c
       \ /
        *
```

## Что делает НЕВЕРНЫЙ код:

```python
# Порядок обхода (BFS-like):
stack = [(*, grad=1)]

# Итерация 1: обрабатываем *
visited.add(*)
*.parent_op.backward_pass()  # Вычисляет градиенты для + и c
stack.appendleft(c)  # добавляем c
stack.appendleft(+)  # добавляем +

# Итерация 2: обрабатываем c
visited.add(c)
c.parent_op.backward_pass()  # ОК, c - лист, parent_op=None

# Итерация 3: обрабатываем +
visited.add(+)
+.parent_op.backward_pass()  # Пытается обновить градиенты для a и b
# ПРОБЛЕМА: + уже получил свой градиент от *?
# НЕТ! Потому что backward_pass() для * уже вызван,
# но градиент для + еще может быть не полностью накоплен!
```

## Почему это неверно:

1. **Нарушение топологического порядка**: `backward_pass()` для узла `*` вызывается до того, как все его входы (`+` и `c`) будут готовы получить градиенты.

2. **Проблема с накоплением градиентов**: Если у узла несколько родителей (например, `a` используется в нескольких операциях), то его градиент должен быть **суммой** градиентов от всех родителей. В неверном коде это не гарантируется.

## Что делает ВЕРНЫЙ код:

```python
# Шаг 1: Построение топологического порядка (от входов к выходу)
topo = [a, b, +, c, *]  # в прямом порядке

# Шаг 2: Устанавливаем градиент потерь
*.grad = 1

# Шаг 3: Идем в обратном порядке
for v in reversed(topo):  # v = *, c, +, b, a
    if v.parent_op:
        v.parent_op.backward_pass()  # Каждый узел обрабатывается после всех своих родителей
```

## В реальной задаче
У меня был exp, который использовал градиент от div в crossEntropy. 
Данный exp видел нулевой градиент от деления, не смотря на то, что он таковым быть не мог

В качестве проверки, проставил print и там и там, и увидел, что exp вызывается раньше div, из-за чего как раз и получается, что градиент был использован еще до полного накопления.

Решено введением двухшагового прохода
